# Neironode — концепция и решения

## Цель
Небольшой сайт IT-команды для представления услуг и получения заказов. Сайт должен помогать клиенту быстро понять, чем команда полезна, и перейти к прямому разговору. Это не самостоятельный SaaS.

## Аудитория и услуги
- Предприниматели: автоматизация повторяющихся процессов, внутренние инструменты, обработка данных.
- Владельцы проектов: серверная логика, базы данных, веб-приложения и API-интеграции.
- Дизайнеры и небольшие студии: техническая реализация сайтов по готовому оформлению.
- Полная разработка сайтов и доработки существующих систем — по согласованию возможностей команды.

Список услуг предварительный; команда уточнит его позже.

## Принятые решения
- Продавать не «технологии», а понятную помощь с задачами клиента.
- Основной сценарий: услуги → «Обсудить проект» → прямое общение (предполагается Telegram).
- Без регистрации, корзины, онлайн-оплаты, сложных брифов и интерактивных конструкторов на первом этапе.
- Стоимость индивидуальных заказов обсуждается отдельно.
- Дизайн: лёгкий, профессиональный, без избыточных прямоугольников, бессмысленных схем и декоративных элементов, похожих на кнопки.
- JavaScript использовать для полезных взаимодействий и спокойных анимаций, без перегруза.
- Только реальные кейсы и подтверждённые факты; SLOTIC можно рассмотреть как собственный проект, но размещение не утверждено.
- «Neironode» — рабочее название; название, логотип, фирменный стиль, контакты и домен ещё не утверждены.

## Разработка и публикация
- На этапе создания сайта используется **одна основная ветка `main`**.
- Изменения в `main` автоматически публикуются на GitHub Pages (после первоначального включения сервиса).
- Просмотр и оценка дизайна происходят по одной постоянной ссылке; изменения при необходимости откатываются через Git.
- Позже, когда сайт начнёт обслуживать реальных клиентов, пересмотреть порядок проверки рискованных изменений.
- После обсуждения с командой возможны размещение на VPS и собственный домен.

## Ближайшие задачи
1. Довести первую версию страницы, улучшить брендинг и главный экран.
2. Уточнить услуги, состав команды и контакт для заявок.
3. Подготовить реальные примеры работ и финальные тексты.
4. Ввести сайт в полноценную эксплуатацию на согласованном адресе.

Не добавлять CRM, личные кабинеты и оплату до появления конкретной потребности.
