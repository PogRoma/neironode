# Neironode

Сайт небольшой IT-команды: автоматизация процессов, backend-разработка, веб-сервисы, API-интеграции и доработка проектов.

**Цель:** показать, чем команда может помочь, и пригласить потенциального клиента обсудить задачу напрямую. Первая версия не предусматривает корзину, регистрацию и онлайн-оплату.

## Статус

Проект на начальном этапе. Реализация сайта разрабатывается отдельно; наличие опубликованного сайта пока не подтверждено.

## Технологии

Для первой версии запланирован статический сайт на HTML, CSS и JavaScript, пригодный для GitHub Pages. Фактическую структуру файлов и команды запуска нужно дополнить после появления реализации.

## Как посмотреть сайт

До появления файлов сайта и настройки публикации эта инструкция неактуальна.

После реализации статической версии:
- Откройте входной HTML-файл в браузере (если сайт не требует dev-сервера).
- Для публикации через GitHub Pages потребуется настроить источник публикации в настройках репозитория и убедиться, что входной файл находится в публикуемой директории.
- После настройки добавьте сюда реальный адрес опубликованного сайта.

В дальнейшем возможен перенос на собственный VPS.
